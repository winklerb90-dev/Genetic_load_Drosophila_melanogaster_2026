The scripts have been written for Unix and R and are structured as followed:
1. Filtering and imputation of genotypes (in Unix)
2. Estimating impact of variants with SnpEff (in R)
3. Calculating rejected substitutions with GERP++ (in Unix)
4. Statistical analysis with brms (in R)
5. Visualisation (in R)
\
The attic directory contains scripts which have been dismissed at some point during the project (like alignments of DGRP fasta files).
